# Electric-utility-revenue-and-billing-dashboard
This is a dashboard with Overview, Revenue Analysis, and Customer/Billing Breakdowns from synthetic data for January 2024 through August 2026 (retrieved from https://www.imagine.art/imagine-computer/ai-spreadsheet-generator)

The first page lists KPIs for Total Revenue, Total Customers, Total KWh, Average Bill, and the percentage of bills that were collected and not outstanding.
The donut chart shows Total Revenue by Customer Class
